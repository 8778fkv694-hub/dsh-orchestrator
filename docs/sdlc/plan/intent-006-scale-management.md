# INTENT-006 v1 · 管理看板规模化：分类、排序与常用优先（候选，待机主确认）

状态：**accepted**；日期：2026-10-30；发起人：机主；整理者：DeepSeek Harness Agent。
确认来源：机主在 DSH 会话确认复述与范围（选择 A：分类+排序+置顶+分页全量实施；默认排序选择 A：置顶 → 待你决定 → 最新更新）。

## 原始输入（机主原话）

> “我再增加一条，就这个管理界面啊，一般来说，如果数量多的话，你就一个是要分类，第二个要显示最常用的、最新的放在前面等等这些管理功能，你策划一下，这也是我的一条需求啊，你转化好。”

## AI 复述（确认对象）

当运行、管线、输出物的数量变多时，管理看板必须仍然**好找、好看、好操作**：

1. **分类**：管线按分类/标签分组（分类来自目录约定或可选索引元数据，未标注则“未分类”）；运行按状态 + 时间（今天/近 7 天/更早）+ 所属管线分组；输出物按类型/日期/所属运行分组。组头显示数量，可折叠；分组状态记住。
2. **排序**：默认“最新优先”（更新/开始时间倒序）；可切换“最常用”（按运行次数/最近使用）、“名称”、“状态”；选择按视图记住。
3. **常用与置顶**：管线和运行可本地置顶/收藏（只存在本机，不上传）；“最常用”由运行历史推导（运行次数、最近使用），无运行记录的管线不伪造热度。
4. **规模**：搜索 + 分类 + 筛选组合；列表用“加载更多/分页”而不是一次把全部内容铺满；列表接口支持 limit/offset/筛选（或客户端分装备份），单页渲染有上限；大数量下首屏仍然快。
5. **默认秩序**：需要人决定的排最前（待你决定/失败），其次进行中（最新在前），然后近期完成；不需要用户先配置就能用。
6. **零配置**：不要求手写分类；目录/文件名即可作为初始分类，索引元数据是可选增强；设置、筛选、排序、折叠状态记住。

## 不做什么

- 不做多用户/服务端账号共享的收藏与置顶；偏好只存本机。
- 不做删除/归档等破坏性记录管理（仍需另获授权与清理审计）。
- 不改变 `orch_*` 工具语义、运行状态与人工确认边界；不调模型、不推送外部。
- 不为了“常用”伪造数据：没有运行历史的管线显示 0 次。

## 成功判据（可观察）

1. 在 **200 个运行、50 条管线、200 个输出物**的合成数据下：首屏可读、分组/排序/搜索可用、默认最新优先、无需配置。
2. “最常用”顺序与运行次数、最近使用一致；置顶项固定在前；无历史的管线显示 0。
3. 列表支持加载更多/分页，切换分组/排序不丢筛选与搜索；刷新后设置仍保留。
4. 窄屏可用；测试覆盖排序/分组/分页与大数据量；截图给机主目视验收。
