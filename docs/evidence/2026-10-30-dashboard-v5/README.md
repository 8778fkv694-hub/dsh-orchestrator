# 2026-10-30 · 看板 v5 / 开箱即用与规模化（INTENT-005、INTENT-006）实现证据

依据：机主确认的 [INTENT-005](../../../docs/sdlc/plan/intent-005-out-of-box.md)（开源项目开箱即用）与 [INTENT-006](../../../docs/sdlc/plan/intent-006-scale-management.md)（管理看板规模化）；SPEC v5 S33–S46；设计稿见 [dashboard-design-2026-10-30](../../../docs/sdlc/design/dashboard-design-2026-10-30.md)。

## 本轮实现

- **一条命令起步**：`npm run quickstart` 创建/重置 `.demo-workspace/`（合成数据、无模型/凭据），生成示例管线与不同状态的运行/输出物，启动看板并打印带 token 的本机 URL；支持 `--port`、`--open`（默认不自动弹）、`--read-only`；启动前做 Node 版本/目录可写/端口占用的人话检查。
- **默认好用**：看板增加「自动跟随」开关（默认开）：输出物视图自动选中最新文件并在文件更新后自动刷新预览；自动打开外部新标签默认关闭。视图/筛选/排序/分组/折叠/置顶/分页等设置本机记住。
- **结构化展开与分类**：管线库按分类分组（目录约定 + 可选 `pipelines/index.json` 标注分类/标签/置顶/最常用）；运行默认「置顶 → 待你决定 → 进行中 → 当天/近 7 天/更早完成」；可切换按状态/时间/管线分组与最新/最常用/状态/名称排序。
- **规模化**：运行记录、输出物与看板支持加载更多；仅渲染当前页；合成 36 运行/2 管线/26 输出物下操作流畅。
- **Harness 内 skill**：随仓库提供 `skills/dsh-orchestrator/SKILL.md`（建管线/工作单/人工门/暂停/继续/取消/对账/看板配方），news-briefing 项目也放入 `.agents/skills/`；不改变权限，不允许模型代点人工门。
- **运行记录与输出物**（v4 已交付）：记录视图含状态/进度/收据/开始/耗时/更新与导出 JSON；输出物只读列出 `output/` 文件并可内嵌预览/打开/复制路径。

## 验证

- 看板测试 **17/17**（TAP：`node-tests-viewer.tap`）；全量测试 **49/49**（新增 pipeline index 元数据 1 项）。
- quickstart 实测（`quickstart.log`）：Node 22+、端口 8893、页面 200、4 个演示运行/1 条管线/3 个输出物，模型调用 0。
- 安全边界：只绑本机回环、逐进程 token、POST 需 token 头 + Origin/Host；输出物只服务 `output/` 下普通文件（≤4MB、拒绝符号链接/越界）并带 CSP sandbox；记录管理只读；置顶/排序只存本机。
- 未调用真实模型；未改宿主；未改新闻项目运行状态。

## 未覆盖/边界

- 运行记录的删除/归档/保留与共享收藏未做（本机偏好、只读管理）。
- 输出物预览对不支持的类型只给打开链接；Markdown 按纯文本预览。
- 大数据量验收为合成 36 运行/26 输出物；更大数据（数百）仍建议后续做服务端分页/虚拟列表。
- 人工门/意图确认仍只在 Harness 会话进行；看板不代替人点。
