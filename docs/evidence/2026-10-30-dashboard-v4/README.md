# 2026-10-30 · 管线管理看板 v4（INTENT-004）实现证据

依据：机主确认的 [INTENT-004](../../../docs/sdlc/plan/intent-004-dashboard.md)（人性化/先进/简单的管理看板 + Harness 内结构化展开与多选项提问）与 [SPEC v4](../../../docs/sdlc/design/spec.md) S22–S32；设计稿见 [dashboard-design-2026-10-30](../../../docs/sdlc/design/dashboard-design-2026-10-30.md)。

## 本轮实现

- **插件侧（Harness 会话）**：gate 支持 `options` 多选项（经 DSH 提问卡由人选择，记录所选值；无 options 仍兼容 confirm/reject）；`orch_*` 回执改为结构化首行摘要 + 分块信息（目标/工作单/操作 ID/证据/下一步），原始 JSON 收进次要代码块。
- **看板侧（`orch view`）**：重写为“总览 → 管线库/运行卡片 → 详情抽屉”三级展开；新增「看板 / 运行记录 / 输出物」视图；运行记录支持状态筛选、搜索、详情、导出 JSON；输出物只读列出 `output/` 文件并可安全打开/复制路径；详情抽屉含步骤流、证据哈希、交付项、时间线（折叠）、原始 JSON（折叠）；实时调度（启动/继续/暂停/取消）带确认与 toast；桌面与窄屏响应式。

## 验证

- 看板测试 **16/16**（TAP：`node-tests-viewer.tap`）；全量 **48/48**（新增 core gate options 2 项、plugin option gate 1 项、outputs 1 项）。
- 安全边界：看板仍只绑定本机回环、逐进程令牌、POST 需令牌头+Origin/Host；输出物只服务 `output/` 下普通文件（≤4MB、拒绝符号链接/越界）并带 CSP `sandbox`；记录管理为只读，不提供删除/归档。
- 未调用真实模型；未改宿主；未改新闻项目运行状态。

## 边界（未覆盖）

- 运行记录的删除/归档/保留策略未做（只读管理；需要独立授权与清理审计）。
- 大历史量的分页/虚拟列表未做（当前假设本地少量运行；快照全量列出）。
- 人工门/意图确认仍只在 Harness 会话进行，看板不提供决定 UI；等待项只给复制 runId/继续提示。
- 输出物是静态只读服务，不执行页面脚本；HTML 以沙箱策略打开。
